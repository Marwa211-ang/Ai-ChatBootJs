# 🚀 AI Chatbot with Gemini API

A fully-featured, intelligent chatbot designed and programmed from scratch using core web technologies and integrated with the power of the **Google Gemini API**.

## ✨ Features:
- **Modern UI/UX:** A sleek and fluid user interface inspired by global chat applications, featuring smooth animations and custom color gradients.
- **Smart File Attachments:** 
  - **Image Processing:** Converts uploaded images to `Base64` format and passes them to the API for vision analysis (accompanied by a green visual indicator on the attachment button).
  - **Code & Text Reading:** Leverages the `FileReader API` to parse source code and plain text files directly (`.css`, `.js`, `.txt`) so the bot can instantly summarize or analyze them (accompanied by a blue visual indicator).
- **Responsive Design:** Fully optimized and responsive across various screen sizes and mobile devices.

## 🛠️ Tech Stack:
- **HTML5:** Semantic structure of the application.
- **CSS3:** Advanced styling, Flexbox layouts, and custom gradients.
- **JavaScript (Vanilla JS):** Core application logic, API integration, and file reading streams.
- **Google Gemini API:** The underlying Large Language Model powering the conversational AI.

## 🗺️ Project Roadmap:
- [ ] **Phase 1: Core Chatbot & Image Analysis** - Building the UI, integrating Gemini API, and implementing Base64 image upload.
- [ ] **Phase 2: File & Code Parsing** - Implementing `FileReader API` to read and attach text, CSS, and JS files directly into the chat.
- [ ] **Phase 3:** Integrate **Local Storage** to persist chat history and prevent data loss on page refresh.
- [ ] **Phase 4:** Implement **Voice Recognition** features to enable real-time audio interaction via the microphone.
